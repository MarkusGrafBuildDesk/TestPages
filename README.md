# TestPages

A small React example app built with Vite. It is a personal note archive with filtering, search, and a working new-note composer.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

Pushes to `main` deploy automatically through GitHub Actions. In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.
